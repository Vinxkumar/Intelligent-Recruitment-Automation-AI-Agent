# Recruitment Automation AI Agent

An AI-powered recruitment system that automates:
- Job description generation
- LinkedIn-style job post creation
- Resume screening & scoring
- Drive management (Active / Inactive toggle)

Built using Flask, MySQL, and LLaMA3 via Ollama.

---

## 🚀 Features

- Create and manage hiring drives
- Toggle drive status (Active / Inactive)
- Generate professional job descriptions
- Generate LinkedIn job posts
- Resume screening with AI-based scoring (1–10)


---

## 🏗️ Tech Stack

- Python (Flask)
- MySQL
- Ollama (LLaMA3)
- HTML / CSS / JavaScript
- REST APIs
